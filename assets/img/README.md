`emoji-*.png`: Noto Color Emoji images (Google, github.com/googlefonts/noto-emoji; images Apache License 2.0, font SIL OFL 1.1),
96x96. Stage 1 rendered them from the font; the stage-2 additions (sunglasses, cross, checkmark, book, note, headphones, bolt,
package, hourglass) are the repository's `2D/png/128` images scaled to 96 px. The web uses the OS emoji font instead.

`icon-*.svg`: the web's inline SVG icons. `dash-*.png`: pre-rendered dashed drop-zone borders. `logo-text.png`: the gradient
"TVFS" logo (Slint has no gradient text). `github.png`, `paper.png`, `tvfs-logo.png`: the web's info-card images.
