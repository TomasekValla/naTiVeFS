Fonts bundled for the UI (all SIL Open Font License 1.1): Inter (Rasmus Andersson), Syne (Bonjour Monde), Space Grotesk (Florian Karsten),
JetBrains Mono (The JetBrains Mono Project Authors, license text in `OFL-JetBrainsMono.txt`).
Inter, Syne and Space Grotesk: static instances generated from the Google Fonts variable fonts (google/fonts repository).
JetBrains Mono: Regular and SemiBold TTF from github.com/JetBrains/JetBrainsMono (`fonts/ttf/`), used by the File Check page like the web.
