naTiVeFS

Get your files uploaded. Natively.

Desktop

Step 1

Download

Download the binary for your architecture.

nativefs-linux-x64 ↓ nativefs-linux-arm64 ↓
Step 2

Install

Run the install script, or do it manually.

Automated:

curl -fsSL https://files.tomasekvalla.cz/get/install-linux.sh | sh

Manual:

chmod +x nativefs-linux-x64
mv nativefs-linux-x64 ~/.local/bin/nativefs

To appear in "Open with" in your file manager, also create ~/.local/share/applications/nativefs.desktop — the install script does this automatically.

Step 3

Log in

Run nativefs. Enter your TVFS password on first launch.

Step 4

Upload

Drag files into the window, use Ctrl+U, or right-click any file and choose Open With → naTiVeFS.

Step 1

Download

Download the binary for your Mac.

Apple Silicon (arm64) ↓ Intel (x64) ↓
Step 2

Install

chmod +x nativefs-macos-arm64
xattr -dr com.apple.quarantine nativefs-macos-arm64
mv nativefs-macos-arm64 /usr/local/bin/nativefs

The xattr step removes the Gatekeeper quarantine flag that blocks unnotarized binaries.

Step 3

Log in

Run nativefs from Terminal or Spotlight. Enter your TVFS password.

Step 4

Upload

Drag files into the window, or use Cmd+U. Right-click → Open With → naTiVeFS works in Finder once the binary is in /usr/local/bin.

Step 1

Download

nativefs-windows-x64.exe ↓
Step 2

Install

Run the PowerShell install script. This copies the binary to %LOCALAPPDATA%\naTiVeFS\ and adds a Send To shortcut.

irm https://files.tomasekvalla.cz/get/install-windows.ps1 | iex

Or just place the .exe wherever you want and run it directly. The Send To shortcut lets you right-click files in Explorer.

Step 3

Log in

Run nativefs.exe. Enter your TVFS password on first launch.

Step 4

Upload

Drag files into the window, use Ctrl+U, or right-click any file → Send to → naTiVeFS.

Android

naTiVeFS is not available as a native Android app. Use the PWA instead — it integrates with the system share dialog.

  1. Open Chrome
  2. Go to files.tomasekvalla.cz/upload
  3. Tap ⋮ → Add to Home Screen

After installation, TVFS appears in the Android share sheet. Tap Share on any file, then select TVFS to upload directly.
